ORBITAL — a gravity-slingshot arcade game. Pilot a tiny probe through five neon star systems: aim with the mouse, hold to charge thrust, release to slingshot around planets whose gravity bends your path. Collect every star to clear a level, chain pickups into combos, and don't crash or drift into deep space. Three lives, limited fuel that recharges while you aim, a time bonus on every level, synthesized WebAudio sound effects, and a dotted trajectory preview so every launch is a real decision. Built from scratch in vanilla JavaScript on canvas 2D — no libraries, no network, no copied assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open `game/index.html` directly.
